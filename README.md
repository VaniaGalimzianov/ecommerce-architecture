---

## Технологический стек системы
* **Backend:** Python / FastAPI
* **Database:** PostgreSQL
* **Caching:** Redis
* **Message Broker:** RabbitMQ (для асинхронных уведомлений и фоновых задач)
* **Monitoring:** Prometheus & Grafana

## Ключевые архитектурные артефакты

Вся проектная документация располагается в директории `docs/architecture/`:

1. **[ADR-001: Выбор архитектурного стиля](docs/architecture/ADR-001.md)**
   * Обоснован выбор **модульного монолита** с перспективой миграции модулей Payments и Notifications в отдельные микросервисы.
2. **[C4 Model: Контекст и Контейнеры](docs/architecture/c4.drawio)**
   * Отражена интеграция с внешним платежным шлюзом, службой доставки и системой SMS/Email нотификаций.
3. **[ER-диаграмма (Схема БД)](docs/architecture/er-diagram.png)**
   * Спроектировано 7 ключевых таблиц. Строго разделены модули пользователей, каталога, остатков (inventory) и заказов.
4. **[OpenAPI 3.0 Контракт](docs/architecture/openapi.yaml)**
   * Спецификация REST API для фронтенда (Web / Mobile) с настроенной схемой авторизации.

Репозиторий практического задания №3 по дисциплине «Создание клиент-серверных приложений».  
Университет ИТМО, Факультет прикладной информатики, 2026.

---

## Предметная область
Система электронной коммерции (интернет-магазин), предоставляющая клиентам возможность просмотра каталога товаров, управления корзиной, оформления заказов, онлайн-оплаты и отслеживания доставки.

---

## Архитектурные артефакты

Все ключевые проектные артефакты расположены в каталоге `docs/architecture/`:

1. **[ADR-001: Выбор архитектурного стиля системы](docs/architecture/ADR-001.md)**
   * Обоснование выбора модульного монолита с элементами Event-Driven Architecture.
   * Анализ компромиссов (Trade-offs: Time-to-Market, Scalability, Cost, Reliability, Maintainability).
2. **[C4 Model: Диаграммы контекста и контейнеров](docs/architecture/c4-diagram.drawio)**
   * Level 1: System Context Diagram (взаимодействие с пользователями, банком и службой доставки).
   * Level 2: Container Diagram (SPA-клиент, API Gateway, бэкенд-сервисы, очереди RabbitMQ, БД PostgreSQL, Redis).
3. **[OpenAPI Контракт](docs/architecture/openapi.yaml)**
   * Спецификация REST API (OpenAPI 3.0), схемы данных (Schemas), механизмы авторизации (JWT / Bearer).
4. **[ER-диаграмма базы данных](docs/architecture/er-diagram.png)**
   * Схема реляционной модели данных (8 ключевых сущностей, типы связей, ограничения целостности).
